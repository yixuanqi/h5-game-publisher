# V0.5.4d2a — bounded linear gradient and solid borders

Base 30efd777793bdecffd04df93e430e3ba4fbef2b5; d1 run 46140612160 confirms 72 JS tests and four pixel-perfect synthetic cases. Keep all existing strict title geometry and paint gates. Add CSS linear gradients with degree or cardinal direction, percentage/implicit stops, supported hex/rgb/rgba colors; calculate endpoints using padding-box projections. Add uniform solid border rings and square single-side/same-color borders; clip overflow to inner padding box. Preserve border style/color declarations in an opt-in paint CSS plan and inline cascade, keeping earlier geometry-only plan behavior. New strict pixel fixture with diagonal/horizontal/vertical gradients, uniform rounded border, bottom border, resize and color mutation, at both viewports. Same pixel threshold as d1; no game-specific offsets or source edits. Unsupported shadows, radial/multilayer gradients, arbitrary border styles, nonuniform rounded borders, currentColor resolution and general CSS paint semantics remain pending; opt-in plan is a bounded subset, not a complete CSS declaration preservation guarantee. No native WX, complete menu rendering or release claims. Main and source unchanged. CI determines status.
