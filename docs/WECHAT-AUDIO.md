# V0.4c audio engineering slice

Build --audio, isolated audio-test saves. Original 69 OfflineAudioContext synthesis recipes are rendered at build time using web-audio-engine, PCM16 mono 24 kHz bank, no external audio assets. This sample rate/quantization is a packaging decision, not exact browser audio parity; report verifies nonzero, finite samples, clipping and quantization error. Original score, biome ambience, voice playback and game triggers retained. Native bridge requires wx.createWebAudioContext and real native AudioBuffers; no fake audio success. CI uses real rendered audio graph through simulated wx, not actual device. Verify WebAudioContext method/AudioParam support, playback latency, sound quality, interruptions, and haptic motor on DevTools and physical iOS/Android before release.
