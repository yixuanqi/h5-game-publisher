# Android 发行检查单

- [ ] 确认 appId、应用名称、版本号、versionCode 单调递增
- [ ] 所有素材有使用权，游戏资源本地可访问，无依赖博客在线地址
- [ ] 飞行模式首次打开、加载全部关卡及音频
- [ ] 安装、覆盖升级、存档保留、卸载重装行为符合预期
- [ ] 横竖屏切换、平板/折叠屏、刘海/导航栏、返回键、后台暂停、音频焦点
- [ ] 真实 Android 手机触控、多点触控、低端性能；连续运行并记录异常
- [ ] App 图标、截图、宣传图、商店描述、联系信息、隐私政策与实际行为一致
- [ ] SDK 版本及 Play 政策在发布时重新核对
- [ ] 检查最终 APK/AAB 版本、包名、权限、签名、校验和，保存构建信息
- [ ] 使用上传密钥签名 AAB 并确认正确的 Play App Signing 账号
- [ ] Play 内部测试、适用的封闭测试与正式发布审批
- [ ] 生产上线前人工确认版本和地区；保留回滚方案
